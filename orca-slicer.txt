# OrcaSlicer / BambuStudio no NixOS — tela branca e travamento

## Status: RESOLVIDO DE FORMA DECLARATIVA (2026-09)

O fix agora está dentro do `configuration.nix`, no helper `wrapGL` no
topo do arquivo. Não é mais preciso wrapper manual em `~/.local/bin`
nem nixGL.

---

## Problema

No NixOS o OrcaSlicer (e o BambuStudio) abre com a **tela branca**:
a janela aparece, mas a interface não renderiza. O erro é silencioso.
Causa: o app não acessa corretamente as bibliotecas OpenGL/GBM do
sistema por causa do isolamento do ambiente Nix.

## O que NÃO fazer

Definir `GBM_BACKEND = "dri"` em `environment.variables` (global).
Isso resolve o slicer mas **derruba o desktop** — foi o que aconteceu
no KDE e o motivo da linha ter ficado comentada na config antiga:

```nix
# environment.variables = {
#   GBM_BACKEND = "dri";  # <- NÃO. Global quebra a sessão.
# };
```

## Solução atual (declarativa, no configuration.nix)

Aplicar a variável **só nesses dois apps**, via wrapper. No topo do
`configuration.nix`:

```nix
wrapGL = pkg: exe: pkgs.symlinkJoin {
  name = "${lib.getName pkg}-glfix";
  paths = [ pkg ];
  nativeBuildInputs = [ pkgs.makeWrapper ];
  postBuild = ''
    wrapProgram $out/bin/${exe} \
      --set GBM_BACKEND dri

    # Os .desktop herdados apontam para o store path ORIGINAL, o que
    # burlaria o wrapper ao abrir pelo menu. Por isso são reescritos.
    for f in $out/share/applications/*.desktop; do
      [ -e "$f" ] || continue
      real=$(readlink -f "$f")
      rm "$f"
      substitute "$real" "$f" \
        --replace-quiet "${pkg}/bin/${exe}" "$out/bin/${exe}"
    done
  '';
};
```

E na lista de pacotes:

```nix
(wrapGL orca-slicer  "orca-slicer")
(wrapGL bambu-studio "bambu-studio")
```

Vantagens sobre o wrapper manual antigo:
- funciona tanto pelo terminal quanto pelo menu do desktop
- some junto com o `nixos-rebuild` se você remover (nada solto no $HOME)
- não depende de `--impure` nem de rede em runtime

### Se ainda der tela branca

Descomente as linhas extras dentro do `wrapProgram`:

```nix
  --set WEBKIT_DISABLE_COMPOSITING_MODE 1 \
  --set __GL_THREADED_OPTIMIZATIONS 0
```

### Para reverter

Troque `(wrapGL orca-slicer "orca-slicer")` por `orca-slicer` na lista
de pacotes e rode `sudo nixos-rebuild switch`.

## FALLBACK: método antigo com nixGL (manual, `~/.local/bin`)

Mantido só como registro. Usar apenas se o método declarativo falhar.

```bash
mkdir -p ~/.local/bin
cat > ~/.local/bin/orca-slicer <<'EOF'
#!/usr/bin/env bash
exec nix run github:guibou/nixGL --impure -- orca-slicer "$@"
EOF
chmod +x ~/.local/bin/orca-slicer
```

Teste direto sem criar o wrapper:

```bash
export NIXPKGS_ALLOW_UNFREE=1
nix run github:guibou/nixGL --impure -- orca-slicer
```

Limitações: só funciona pelo terminal (o menu continua chamando o
binário sem wrapper), exige `--impure` e rede, e o arquivo fica solto
no `$HOME` fora do controle do Nix.
